────────────────────────────────────────────────────────────────────────────────
PART 1 — ONE-TIME SETUP (do this once)
────────────────────────────────────────────────────────────────────────────────

STEP 1: Enable SSH on your ForexVPS
─────────────────────────────────────
1. RDP into your VPS one last time
2. Click Start → search "Services" → open it
3. Scroll down to "OpenSSH SSH Server"
4. Right-click → Properties → set Startup type to "Automatic" → click Start
5. Click OK

If you don't see "OpenSSH SSH Server" in the list:
1. Click Start → Settings → Apps → Optional Features
2. Click "Add a feature"
3. Find "OpenSSH Server" → click Install
4. Then go back to Services and set it to Automatic + Start


STEP 2: Find your VPS IP address
──────────────────────────────────
Your VPS IP address is in the email ForexVPS sent you when you ordered.
It looks like: 185.123.45.67
Save this — you'll use it every time.


STEP 3: Set up a shortcut on your Mac
───────────────────────────────────────
Open Terminal on your Mac (press Cmd+Space, type Terminal, press Enter).

Run this command — replace the values with YOUR actual details:

  echo 'alias vps="ssh Administrator@YOUR.VPS.IP.HERE"' >> ~/.zshrc && source ~/.zshrc

Example with a real IP:
  echo 'alias vps="ssh Administrator@185.123.45.67"' >> ~/.zshrc && source ~/.zshrc

Now you can connect to your VPS just by typing: vps


STEP 4: Test the connection
─────────────────────────────
In Mac Terminal type:
  vps

It will ask for your VPS password (the one ForexVPS emailed you).
Type it and press Enter. You should see a Windows command prompt appear.
Type 'exit' to disconnect.

────────────────────────────────────────────────────────────────────────────────
PART 2 — DAILY COMMANDS (after setup is done)
────────────────────────────────────────────────────────────────────────────────

All commands below are typed in your Mac Terminal.
They connect to the VPS, run the command, and disconnect automatically.


CHECK STATUS (are bots running?)
──────────────────────────────────
  ssh Administrator@YOUR.VPS.IP python C:\algos\controller.py status


START BOTH BOTS
────────────────
  ssh Administrator@YOUR.VPS.IP python C:\algos\controller.py start both


START BOT 1 ONLY
─────────────────
  ssh Administrator@YOUR.VPS.IP python C:\algos\controller.py start bot1


START BOT 2 ONLY
─────────────────
  ssh Administrator@YOUR.VPS.IP python C:\algos\controller.py start bot2


STOP BOTH BOTS (graceful — lets open trades finish)
────────────────────────────────────────────────────
  ssh Administrator@YOUR.VPS.IP python C:\algos\controller.py stop both


STOP BOT 1 ONLY
────────────────
  ssh Administrator@YOUR.VPS.IP python C:\algos\controller.py stop bot1


STOP BOT 2 ONLY
────────────────
  ssh Administrator@YOUR.VPS.IP python C:\algos\controller.py stop bot2


EMERGENCY STOP (kills bots immediately)
────────────────────────────────────────
  ssh Administrator@YOUR.VPS.IP python C:\algos\controller.py emergency

⚠  This stops new trades instantly. Open positions are still protected
   by your broker stop losses. To close open positions, log into MT5.


RESTART BOTH BOTS
──────────────────
  ssh Administrator@YOUR.VPS.IP python C:\algos\controller.py restart both


VIEW LIVE BOT 1 LOG (last 50 lines)
─────────────────────────────────────
  ssh Administrator@YOUR.VPS.IP type C:\algos\bot1_trend.log | tail -50


VIEW LIVE BOT 2 LOG (last 50 lines)
─────────────────────────────────────
  ssh Administrator@YOUR.VPS.IP type C:\algos\bot2_reversion.log | tail -50

────────────────────────────────────────────────────────────────────────────────
PART 3 — SHORTCUT ALIASES (optional but recommended)
────────────────────────────────────────────────────────────────────────────────

Add these to your Mac Terminal so you can type short words instead of long commands.
Run this block once in Terminal (replace YOUR.VPS.IP with your actual IP):

cat >> ~/.zshrc << 'EOF'

# XAUUSD Bot Controls
VPS_IP="YOUR.VPS.IP.HERE"
alias bot-status="ssh Administrator@$VPS_IP python C:\algos\controller.py status"
alias bot-start="ssh Administrator@$VPS_IP python C:\algos\controller.py start both"
alias bot-stop="ssh Administrator@$VPS_IP python C:\algos\controller.py stop both"
alias bot-emergency="ssh Administrator@$VPS_IP python C:\algos\controller.py emergency"
alias bot-restart="ssh Administrator@$VPS_IP python C:\algos\controller.py restart both"
alias bot-log1="ssh Administrator@$VPS_IP type C:\algos\bot1_trend.log"
alias bot-log2="ssh Administrator@$VPS_IP type C:\algos\bot2_reversion.log"
EOF
source ~/.zshrc

After running that, your commands become:
  bot-status      → check if bots are running
  bot-start       → start both bots
  bot-stop        → stop both bots gracefully
  bot-emergency   → emergency kill
  bot-restart     → restart both
  bot-log1        → view Bot 1 log
  bot-log2        → view Bot 2 log

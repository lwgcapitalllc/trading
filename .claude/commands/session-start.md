Start a new working session.

1. Read docs/CONTEXT.md fully — especially `## What Was Done` and `## What I Am Working On`.
2. Read CLAUDE.md if not already loaded.
3. Check git status for any uncommitted changes from a previous session.
4. Summarize in 3-5 bullets: current system state, what was last worked on, and what's next.
5. Ask the user what they want to work on today.

Do not start editing files until step 5 is answered.

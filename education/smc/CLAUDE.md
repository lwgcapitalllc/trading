# CLAUDE.md — education/smc/

**Purpose:** The SMC engine course library — the source material the whole repo
is built around. Read before editing anything here. Lives under `education/` so
other courses can be added as sibling folders later.

## What this is

Transcripts and our own summaries of the SMC engine trading course. The engines,
strategies, and indicators in this repo implement the concepts taught here, so
this is the reference we check logic against. Built for study and for handoff to
Aaron's brother to review.

Personal use — both are paid members of the course. Not for redistribution
outside this repo.

## Layout

Organised by **module**, in course order. Each module is a `NN-<slug>/` folder
with its own transcripts and summaries.

```
education/smc/
├── README.md              ← index of every video (AUTO-GENERATED — do not hand-edit)
├── modules.txt           ← the course's module ORDER (single source of truth)
├── 01-start-here/
│   ├── transcripts/       ← NN-<slug>.txt (clean) + NN-<slug>.en.vtt (raw captions)
│   └── summaries/         ← NN-<slug>.md — one summary per video
├── 02-smc-engine-training/
│   └── …
└── 05-my-full-trading-strategy/
    └── …
```

- Module folder `NN` = the module's position in `modules.txt` (course order),
  **not** rip order — so a module lands correctly even if ripped late.
- Video `NN` = the order videos were ripped **within that module**.
- Reorder the library by editing `modules.txt`, then re-run the index generator.
- The `README.md` table is regenerated by `tools/skool-transcript/lib_index.py`
  after every rip. Edit the **summaries**, not the table.

## How content gets here

Ripped with [`tools/skool-transcript`](../../tools/skool-transcript/): copy the
video's m3u8 URL from Chrome DevTools, run `skool-transcript -m "<Module>"`, type
the title. The tool writes the transcript into that module's folder, creates a
summary stub, and updates the index. Videos on Skool's player and on Loom are
both handled automatically. Without `-m`, a video lands in `00-unsorted/`.

## Summaries

Each summary starts as a stub from `tools/skool-transcript/templates/summary.md`
with front matter:

```
title:  human title
video:  NN-slug
status: to-summarize | in-progress | done
```

`status` drives the badge in the index — set it to `done` when a summary is
finished. Keep summaries plain-English and pointer-first: what the video teaches,
the rules/mechanics, and how it maps onto our engines.

## Don't

- Hand-edit `README.md` — it's regenerated and your changes will be lost.
- Commit m3u8 URLs or tokens (they're per-session and expire anyway).
